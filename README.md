# 30-Day Red Team Progress Tracker 🛡️

A **personal cybersecurity learning dashboard** built with React 18, TypeScript, Tailwind CSS v4, Recharts, and Lucide React.

## Features

- ✅ All 30 days pre-seeded across 4 weeks
- 📊 Real-time progress analytics
- 🔥 Streak tracking
- 💾 localStorage persistence (no backend needed)
- 📱 Fully responsive (desktop + mobile)
- 🌙 Dark cybersecurity-themed UI

## Weeks

| Week | Topic | Days |
|------|-------|------|
| 1 | Linux + Networking | 1–7 |
| 2 | Web Application Hacking | 8–14 |
| 3 | Advanced Web + API Security | 15–21 |
| 4 | Windows + Active Directory | 22–30 |

## Tech Stack

- **React 18** + **TypeScript**
- **Vite** (bundler)
- **Tailwind CSS v4** (@tailwindcss/vite)
- **Recharts** (analytics charts)
- **Lucide React** (icons)
- **localStorage** (persistence)

## Getting Started

```bash
npm install
npm run dev
```

## Build & Deploy

```bash
npm run build
# then deploy the dist/ folder to any static host
```

## Disclaimer

> This tracker is for personal learning only. All practical activities must be conducted exclusively on systems you own or have explicit written authorization to test.
